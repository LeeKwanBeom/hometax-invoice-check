# 산출물 서식 규격

**색상 헥스코드와 서식 문자열은 `config/check-config.json` 의 `colors` / `format`
블록이 유일한 출처다.** 이 문서에 헥스코드를 적지 않는다. 두 곳에 적으면
반드시 어긋나고, 어긋난 쪽이 어느 쪽인지 알 수 없게 된다.

구현은 `scripts/build_report.py` 의 `Style` 클래스가 config 를 읽어 만든다.

## 시트 구성

시트 이름도 config(`sheets`)에서 읽는다. `validate.py` 가 같은 값으로 검증한다.

| 순서 | 시트 | 내용 |
|---|---|---|
| 1 | 매트릭스 | 공급자 × 월. 점검대상 먼저, 대상외 나중 |
| 2 | 미수취목록 | 등급순 조치 목록 |
| 3 | 대상외공급자 | vendors.json 에 없는데 등장한 곳 |
| 4 | 원본정제데이터 | 전 건 (상계 표시 포함) |

## 매트릭스 셀 규칙

**셀에는 금액만 넣는다.** 건수·구분을 문자열로 섞으면 합계·정렬이 안 되고
엑셀에서 필터링도 못 한다. 건수는 원본정제데이터에서 세면 된다.

| 상태 | 값 | 채우기 |
|---|---|---|
| 정상 수취 | 순공급가액 (숫자) | 없음 |
| 미수취 | **비움 (None)** | 없음 |
| 발행 후 전액취소 | `0` | `colors.cancelled` |
| 발급기한 전 | 비움 | `colors.grade_grace` |

미수취를 빈칸 + 채우기 없음으로 두는 이유: 빨간 칸이 240개면 아무것도 안 보인다.
조치 대상은 미수취목록 시트에서 등급으로 걸러 본다.

`validate.py` 는 이 규칙을 **양방향으로** 검사한다.
"공란인데 취소색이 칠해진 칸"과 "0인데 노랑이 아닌 칸"을 둘 다 찾고,
**검사 대상을 하나도 못 찾으면 PASS 가 아니라 FAIL 을 낸다.**
0건 매칭 PASS 는 검증이 아니라 검증하는 척이다.

## 미수취목록 등급 색

| 등급 | config 키 |
|---|---|
| 확인 필요 | `grade_action` |
| 기한 전 | `grade_grace` |
| 정상 / 거래 종료 / 해결 | `grade_normal` |
| 단발·비정기 | `grade_sporadic` (null = 채우기 없음) |

정렬 순서는 `GRADE_ORDER` — 확인 필요 → 기한 전 → 단발 → 정상 → 종료 → 해결.
위에서부터 읽으면 조치 대상이 먼저 나온다.

## 열 규칙

- 폰트는 config `format.font`
- 금액은 `format.money`, 날짜는 `format.date`
- 틀고정은 **config 에 값으로 두지 않는다.** 제목 줄·신고기 밴드 때문에 헤더 행
  번호가 시트마다 다르고 실행 시점에 따라 달라진다. 코드가 헤더를 append 한 직후
  `ws.max_row` 로 헤더 행을 읽어 그 **바로 아래**를 얼린다.
  헤더 행 자체를 얼면 스크롤할 때 헤더가 사라진다
- 월 컬럼 개수는 `range(1, 실행월+1)`. **고정값을 쓰면 10월에 데이터가 조용히 사라진다**

## 파일명

`config.output.filename_template` 에서 만든다. 기본형:

```
매입_전자세금계산서_수취점검_{year}_{asof}.xlsx
→ 매입_전자세금계산서_수취점검_2026_0906.xlsx
```

실행일이 파일명에 들어가므로 이전 실행 결과를 덮어쓰지 않는다.
월 1~2회 실행에서 지난달 파일과 나란히 두고 비교할 수 있다.
